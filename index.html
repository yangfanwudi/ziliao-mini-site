特性Features

三大练习模式，加一个 AI 杀手锏 Three practice modes and one AI ace

小程序端共三个页面：首页考种导航、卡片式刷题、错题本。围绕它们，是这些已经实现的能力（在本地联调中全部可跑通）。 The mini program has three pages — exam-type home, card-based quiz, wrong-question book — and these capabilities, all working in local integration today.

📝

历年真题演练Past-paper drills

按考种随机抽 10–20 题组卷；卡片式作答，单选 / 多选 / 判断实时判分（多选须集合完全一致），交卷即得得分汇总与正确率。 Pull 10–20 random questions per exam type and answer card by card. Single, multiple and true/false questions are graded instantly — multiple-choice answers must match exactly as a set — with a score summary when you finish.

🎯

考点专项特训Knowledge-point training

输入知识点关键词，跨考种检索同考点题目集中突破；每道题都带考点标签，薄弱点逐个击破。 Enter a knowledge-point keyword to pull matching questions across every exam type. Each question carries its knowledge-point tag, so weak spots get picked off one by one.

📕

我的错题本Wrong-question book

答错自动进本（复习次数 +1），答对自动置为已掌握；「待攻克 / 已掌握 / 全部」三态过滤，支持去重练与一键清零重练。 Wrong answers file themselves in (review count +1) and correct ones mark questions as mastered. Filter by pending, mastered or all, then de-duplicate and reset the whole book for a fresh round.

🔥

一键举一反三One-tap derived questions

对任意一题，AI 提取核心考点、更换背景场景、加入强干扰项，实时变造出同类新题；无库存时后台异步生成（HTTP 202 + 前端每 2 秒轮询），做完原题立刻能练同类。 For any question, the AI extracts the core knowledge point, swaps the scenario and adds strong distractors to mint fresh variants. If none are in stock, the backend generates them asynchronously (HTTP 202 + 2-second client polling), so the follow-up drill is ready right after you finish the original.

公式不再乱码Formulas that just render

题干与详解完整渲染 Markdown 排版；LaTeX 数学命令先离线转换为 Unicode 数学符号（√x、½、R₁ × R₂…），零外网依赖，真机与审核都稳，异常时自动回退纯文本。 Stems and analyses render full Markdown, and LaTeX math is converted offline into Unicode symbols (√x, ½, R₁ × R₂…) before rendering — zero network dependency, safe on real devices and in review, with automatic fallback to plain text.

智能流水线The Pipeline

一套全自动的「真题 → 题库」流水线 A fully automated paper-to-bank pipeline

从试卷文件到可刷的题，中间没有人工搬运。FastAPI 后端用三个 Agent 串起切片、命题与盲测校验。 From raw paper files to drillable questions with no manual copywork in between. A FastAPI backend chains three agents for slicing, deriving and blind verification.

1

切片入库Slice & import

上传 .pdf / .txt / .md 试卷，自动清洗页眉页脚与干扰字符；LLM 强制输出严格 JSON（json-repair 降级 + 最多重试 3 次），经 Pydantic 校验后入库为 original 真题。 Upload a paper in .pdf / .txt / .md; headers, footers and noise are scrubbed automatically. The LLM is forced to emit strict JSON (json-repair fallback, up to 3 retries), validated by Pydantic, then stored as an original question.

POST /api/pipeline/extract
2

变造命题Derive

命题 Agent 提取原题核心考点，更换背景场景、保留考点、加入强干扰项，生成 3–5 道「同考点、不同皮」的高仿衍生题。 The deriver agent extracts the original's core knowledge point, swaps the scenario, keeps the point and adds strong distractors to create 3–5 look-alike questions.

POST /api/pipeline/derive
3

双盲自测Double-blind check

盲测 Agent 不看标准答案、独立作答；与标准答案一致才允许入库（source_type = derived 并记 parent_id），不一致则弃用重来，整体最多 3 轮。 A separate blind-tester agent answers without ever seeing the key. Only questions whose answer agrees with the official one enter the bank as derived (with parent_id recorded); the rest are discarded and retried, up to 3 rounds.

blind_tester agent
4

组卷与闭环Drill & close the loop

随机组卷接口按考种 / 知识点抽题，交卷判分并同步错题本；衍生题无库存时返回 202 后台生成，前端轮询取题，练完即闭环。 The random-paper API draws by exam type or knowledge point, grading on submit and syncing the wrong book; missing derived questions trigger a 202 background job the client polls — closing the loop right after practice.

GET /api/exams/random

两种运行模式Two operating modes

Mock：零 Key 跑通全链路Mock: full loop, zero keys 真实：OpenAI 兼容端点Real: OpenAI-compatible APIs

Mock 模式（LLM_MOCK=true）不需要任何 API Key，就能完整跑通切片、衍生命题与盲测闭环，适合演示与自动化测试；真实模式接入任意 OpenAI 兼容端点（DeepSeek / Qwen / Moonshot 等），带 60 秒超时与指数退避重试，未配置 Key 时返回清晰的中文错误而非崩溃。 Mock mode (LLM_MOCK=true) runs the entire pipeline — slicing, deriving, blind testing — with zero API keys, ideal for demos and automated tests. Real mode plugs into any OpenAI-compatible endpoint (DeepSeek / Qwen / Moonshot…) with a 60-second timeout, exponential-backoff retries, and a clear Chinese error message instead of a crash when the key is missing.

单选题Single choice 高考数学真题 考点：综合知识Point: general

（5 分）曲线 y = x / (x + 2) 在点 (−1, −1) 处的切线方程为（   ） (5 pts) The tangent line to the curve y = x / (x + 2) at the point (−1, −1) is (   )

A.y = 2x + 1
B.y = 2x − 1
C.y = −2x − 3
D.y = −2x − 2
查看答案与解析Reveal answer & analysis
正确答案：ACorrect answer: A 解析：∵ y = x / (x + 2)，∴ y′ = 2 / (x + 2)²；切线斜率 k = y′|x = −1 = 2。切线方程为 y + 1 = 2 × (x + 1)，即 y = 2x + 1。故选 A。 Analysis: y = x / (x + 2) gives y′ = 2 / (x + 2)², so the slope at x = −1 is k = 2. The tangent is y + 1 = 2(x + 1), i.e. y = 2x + 1. Answer: A.

在小程序里，这道题答错会自动进入错题本，并能一键举一反三生成「同考点、换场景」的新题。 In the mini program, a wrong answer files this question into the wrong book, and one tap derives fresh questions with the same knowledge point in a new scenario.

已知边界Known boundaries

简答题不自动判分Essays are not auto-graded 提交后直接展示参考答案与解析，供自评；不写入答题记录与错题本。 Reference answers and analyses are shown for self-assessment; essays don't enter records or the wrong book.
扫描件 PDF 暂不支持Scanned PDFs not supported yet 图片型扫描试卷需要 OCR，超出当前范围；文字版 .pdf / .txt / .md 均可导入。 Image-only scans need OCR, which is out of scope today; text-based .pdf / .txt / .md all import fine.
Mock 盲测的边界What the mock blind test proves Mock 模式的盲测由确定性规则通过，验证的是闭环机制本身；真实模型能力以接入真实 LLM 后为准。 In mock mode the blind test passes via deterministic rules — it proves the loop, not the model; real capability is only meaningful once a real LLM is attached.
